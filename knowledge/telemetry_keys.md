# Commerce Telemetry Keys

Numeric metrics
- visits, sessions, add_to_cart_rate, conversion_rate, bounce_rate
- order_count, sales_amount, avg_order_value, items_sold
- ad_spend, paid_clicks, cpc, roas
- temp_c, precip_mm, consumer_confidence, cpi, unemployment_rate, usd_index, retail_sales_index

Text metrics
- top_item
- sale_date

Common comparisons
- Funnel health: visits -> add_to_cart_rate -> conversion_rate -> order_count
- Revenue health: sales_amount, avg_order_value, items_sold
- Marketing efficiency: ad_spend vs roas, cpc vs paid_clicks
